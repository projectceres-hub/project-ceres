# Discord Bot Helper for Session Events

This folder contains helper code and documentation for a future Discord bot that will post session scheduling messages and attach .ics files generated by Project Ceres.

## Session Event JSON Format

The `session-discord-export` command in Project Ceres generates a JSON file (typically `exports/session_event.json`) that contains all the information needed to post a session announcement to Discord.

The JSON file contains the following fields:

- **title** (string): The session title/name
- **description** (string or null): Optional session description or notes
- **start_iso** (string): ISO8601 datetime string for the session start time (e.g., "2025-07-27T18:00:00-04:00")
- **end_iso** (string or null): ISO8601 datetime string for the session end time, or null if not specified
- **duration_minutes** (integer): Duration of the session in minutes
- **timezone** (string): Timezone identifier (e.g., "America/New_York", "UTC")
- **ics_path** (string): Absolute or relative path to the .ics calendar file on disk
- **ics_filename** (string): Filename of the .ics file (e.g., "next_session.ics")
- **message_text** (string): The full formatted "Next Session" message block from Promitor, ready to post to Discord
- **google_calendar_url** (string or null): Optional Google Calendar deep-link URL for adding the event to Google Calendar

### Example JSON Structure

```json
{
  "title": "Session 42: The Final Battle",
  "description": "We're finally confronting the BBEG!",
  "start_iso": "2025-07-27T18:00:00-04:00",
  "end_iso": "2025-07-27T22:00:00-04:00",
  "duration_minutes": 240,
  "timezone": "America/New_York",
  "ics_path": "E:/GM Assistant/exports/next_session.ics",
  "ics_filename": "next_session.ics",
  "message_text": "Next Session: Session 42: The Final Battle\n\n📅 Monday, July 27, 2025 at 6:00 PM (UTC-04:00)\n⏱️  Duration: 4 hours\n\n📎 Add to Calendar: file:///E:/GM Assistant/exports/next_session.ics\n\nWe're finally confronting the BBEG!",
  "google_calendar_url": null
}
```

## Future Discord Bot Behavior

The intended flow for a future Discord bot integration:

1. **Read the JSON file**: Load `session_event.json` (or a path specified via configuration)
2. **Load the .ics file**: Read the calendar file from the path specified in `ics_path`
3. **Post message**: Send `message_text` to a specific Discord channel (configured via bot settings)
4. **Attach .ics file**: Upload the .ics file as a Discord attachment so users can download it
5. **Optional link**: If `google_calendar_url` is not null, include it as a clickable link in the message

### Implementation Notes

- The bot should validate that the `ics_path` file exists before attempting to upload it
- The `message_text` field already contains formatted text with emojis and structure; it can be posted as-is or with minor Discord-specific formatting adjustments
- The bot should handle both absolute and relative paths for `ics_path`
- Error handling should gracefully handle missing files or invalid JSON

## Current Status

As of now, this folder only provides:
- Documentation of the JSON contract (this README)
- A JSON schema for validation (`session_event_schema.json`)
- A local preview script (`preview_session_event.py`) that shows what a Discord bot would post

Actual Discord integration (API calls, bot registration, channel posting) will be added in a separate step.

## Usage

To preview what a session event would look like when posted to Discord:

```bash
python helpers/discord_bot/preview_session_event.py
```

Or specify a custom JSON file path:

```bash
python helpers/discord_bot/preview_session_event.py exports/session_event.json
```
